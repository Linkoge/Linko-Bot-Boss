# Autonomy policy

The manager delegates complete objectives to native Codex. Reading, editing, creating files/directories, running commands, installing dependencies, testing, debugging and ordinary Git work need no routine owner approval or project configuration.

Workers preserve user work and ask for explicit confirmation before catastrophic broad destruction. Native questions persist in SQLite and require explicit answers. The returning manager may mark an assignment waiting and ask the user when Codex reports a conversational confirmation request. This remains an agent-recognized boundary; see [security](security.md).

No planner, verification-command registration, permission profiles, capability broker or integration controller runs. Workers validate according to deterministic [verification tiers](VERIFICATION_TIERS.md). Only Risky work gets one automatic cheap read-only diff review; workers report results briefly. The scheduler includes all active projects automatically, under global capacity and one worker per project.

Conversation mode is read-only; Auto delegates requested work; Execute treats the message as a work objective through the same manager path. Worker results automatically resume their original conversation.

The superseded supervised-runner policy is retained in [Git history](https://github.com/Linkoge/Linko-Bot-Boss/blob/20f008f/docs/AUTONOMY_POLICY.md).
